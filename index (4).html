Portfolio AI Chatbot

A lightweight, embeddable chat widget backed by a Cloudflare Worker.

Click the chat button in the bottom-right corner and try asking about skills, services, or projects.

Embed it on any site

<script src="chat.js"
        data-worker="https://YOUR-WORKER.workers.dev"></script>

Without a Worker URL the widget still works using built-in FAQ answers. Source code and setup steps are in the repository README.
